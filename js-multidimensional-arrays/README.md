# Manipulating Multidimensional Indexed and Associative Arrays (JavaScript)

## Brief Summary
This project demonstrates the use and manipulation of multidimensional indexed and associative arrays. It covers creating arrays, adding new elements, deleting array elements, accessing specific values, displaying cities, searching for a product based on a date, and displaying the last array element. Array methods (`push`, `forEach`) and the `delete` operator are used.

## Task
**Part 1 - `details` (indexed):** fields name, address, age, gender. Add `['Ash', 'Tokyo', '20', 'Male']`, delete the first item from the 0th array, display only cities, display the last array.

**Part 2 - `product_details` (associative):** keys product_name, price, date, address. Add `['TV', 2000, '06-01-2024', 'Hubli']`, delete the first item, display the product_name of date 06-01-2024, display the last array.
